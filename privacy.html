Privacy Policy for Health Sync

Last updated: 17 September 2026

What this application is

Health Sync is a personal-use application built and operated by one individual, for that individual's own use only. There are no other users, no user accounts, and no sign-up. No one else's data is ever processed.

What data the application reads

With my own explicit consent through Google's OAuth consent screen, the application reads my own health and fitness data from the Google Health API. This may include activity and workout records, step counts, heart rate, sleep records, and body measurements. It reads only my own Google account data, and only the scopes I have granted.

How the data is used

The data is used solely for my personal review and record keeping. It is not used for advertising, profiling, analytics about other people, or any commercial purpose.

Where the data is stored

Retrieved data is stored on my own private server, under my sole control. It is not stored on this website. This website is a static page and collects nothing: no accounts, no forms, no cookies, no analytics, and no tracking.

Sharing

The data is never sold, rented, traded, or shared with any third party. It is not transferred to any other application or service. Access is limited to me.

Retention and deletion

I retain the data on my own server for as long as it is useful to me, and I can delete it at any time. Access can be revoked at any time from my Google Account permissions page at myaccount.google.com/permissions.

Contact

Questions about this policy can be sent to buckie2001@gmail.com.
