# health-sync-site

Static GitHub Pages site that provides the homepage and privacy policy for
Health Sync, a personal-use Google Cloud OAuth application that reads my own
health data from the Google Health API and stores it on my own private server.
The site exists only to satisfy Google's OAuth consent screen branding
requirements and to allow domain ownership verification in Google Search
Console. It is plain static HTML with no frameworks, no build step, no external
assets, and no tracking.

- Privacy policy: https://buck030.github.io/health-sync-site/privacy.html
